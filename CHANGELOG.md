# Changelog

All notable changes to CodeSprint for JetBrains IDEs are documented here.

## 1.0.0

- Initial release for Android Studio and all IntelliJ-based IDEs (2023.3 and newer), ported from the CodeSprint VS Code extension.
- Tool window dashboard with a Pomodoro focus timer (25 / 5 / 15 minutes by default), start, pause, resume, reset and session-type switching.
- Timestamp-based timer that survives IDE restarts; a session that finishes while the IDE is closed is credited on the next start.
- Daily goal with presets and a custom target, plus statistics for today, sessions, weekly focus time, goal completion, current streak and longest streak.
- Seven day overview chart and daily motivational messages.
- Status bar timer widget; click to start, pause or resume.
- Notifications when a session ends, with a one-click action to start the suggested break or the next focus session.
- Periodic motivational quotes (status bar, notification or both), configurable from Settings | Tools | CodeSprint.
- Native look and feel: follows the IDE theme and scaling, with keyboard navigation and accessibility labels.
- All data stored locally; no account, no network access, no telemetry.
